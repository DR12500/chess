# chess

Personal chess trainer (chess.com-style) for the owner's own devices: Windows PC, iPad, Android phone.
Play against Stockfish whose strength adapts to the player's rating, rated puzzles, lessons and an opening guide.
Up to 3 accounts, synced between devices.

## Tech stack
- Language / runtime: TypeScript, runs in the browser as an installable PWA (no native apps: iPad native would need a Mac + paid Apple account)
- Frameworks / libraries: React 18, Vite 6, vite-plugin-pwa, chess.js (rules), chessground (board UI), stockfish (npm, v19 WASM "lite single-threaded" build), qrcode + jsqr (sync QR), Vitest
- Hosting: GitHub Pages (static) via `.github/workflows/deploy.yml`

## Commands
```sh
# install:  npm install
# run:      npm run dev          # also on LAN: http://<pc-ip>:5173 (PWA install needs HTTPS → use GitHub Pages)
# test:     npm test             # Vitest: rating math, bot mapping, sync merge, all lesson/opening/puzzle moves
# lint:     npm run typecheck    # tsc --noEmit (no ESLint configured)
# build:    npm run build        # copies engine, typechecks, builds dist/
```
Node is installed at `C:\Program Files\nodejs` (via winget); in Git Bash you may need `export PATH="/c/Program Files/nodejs:$PATH"`.

## Project structure
- `src/lib/rating.ts`: Glicko-1 (chess.com's system) and Elo, presets, per-account `RatingConfig`
- `src/lib/sound.ts`: WebAudio sound player; files in `public/sounds/<set>/` (see CREDITS.md)
- `src/lib/pwa.ts`: install prompt + service-worker update checks; `src/components/Qr.tsx`: QR show/scan
- `src/lib/botStrength.ts`: rating → Stockfish settings (UCI_Elo ≥1320; custom weakening below)
- `src/lib/engine.ts`, `src/lib/bot.ts`: Stockfish web-worker wrapper and the opponent
- `src/lib/model.ts`: synced data model, merge, derived stats (ratings are *replayed* from records, never stored)
- `src/lib/gist.ts`, `src/lib/store.ts`: GitHub Gist sync, app state (localStorage), React hook
- `src/lib/review.ts`: game review move classification / accuracy
- `src/pages/*`: Home, Play, Review, Puzzles, Learn (lessons + openings), Profile (stats), Settings (+ onboarding)
- `src/content/lessons.ts`, `src/content/openings.ts`: learning content (validated by `tests/content.test.ts`)
- `public/puzzles.json`: 3120 puzzles sampled from the Lichess puzzle DB (CC0), 120 per 100-pt band 400–2999; regenerate with `python -I scripts/fetch_puzzles.py public/puzzles.json` (needs `pip install zstandard`)
- `token.txt` (owner's GitHub token) is gitignored: never commit it.
- `public/engine/`: generated by `scripts/copy-engine.mjs` (gitignored)

## Conventions
- Every lesson FEN/move and opening line must replay legally; add content only together with a passing `npm test`.
- Bot strength anchors below 1320 are estimates; if changed, keep them monotonic (tested).
- Keep the app fully static: no own server. Sync goes only through the GitHub Gist API.

## Notes / decisions
- **Sync**: one secret Gist (`chess-trainer-sync.json`) per GitHub account, accessed with a classic PAT that has only the `gist` scope. Each device stores token + gist id ("sync code" = `token:gistId`). Merge = union of game/puzzle records by id + last-writer-wins on profile fields; ratings are recomputed by replaying records in time order, so offline play on several devices merges without conflicts.
- **Ratings**: Glicko-1 (chess.com) or Elo, configurable per account and synced (`profile.ratingConfig`); changing it recalculates history. Default preset "Chess.com-like": start RD 185, min RD 55 (≈ ±76 first game vs equal bot, ±8 after ~40 games). Changed from Glicko-2/RD 350 on 2026-11-19 because swings felt too drastic. Bot RD 60, puzzle RD 75. Hints in a rated game make it unrated.
- **Sync via QR**: QR encodes `<app-url>#sync=<token:gistId>`; scanned by the in-app camera scanner (needed on iPad since the home-screen app has separate storage from Safari) or opened as a link.
- **Updates**: vite-plugin-pwa `registerType: 'prompt'`; app checks for a new service worker on start, on focus and every 30 min and shows an "Update" banner. Version = package version + commit hash (GITHUB_SHA in CI).
- **Sounds**: Lichess sets by Enigmahack (AGPLv3+). Lichess's default "standard" set is non-free, don't use it. Project license is therefore AGPL-3.0-or-later.
- **Bot**: ≥1320 uses Stockfish `UCI_LimitStrength`/`UCI_Elo` with a virtual 60s+0.6s clock (Stockfish's calibration TC). <1320: Skill Level 0 + shallow depth + MultiPV softmax + random-move chance.
- **Engine build**: lite single-threaded WASM, because it needs no cross-origin isolation (GitHub Pages can't set COOP/COEP headers) and works on iOS Safari.
- GitHub Pages on a free account requires a **public** repo; only code is public, the Gist with data is secret.
- No time controls yet (untimed games).
